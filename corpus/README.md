# Corpus

Sources and personal records for human use and agent retrieval.

- [Courses](courses/README.md): teaching materials and coursework.
- [Projects](projects/README.md): implementation context and work records.
- [Research](research/README.md): reusable technical learning, organized by field.

Keep one primary home per item; link across areas. Source checkouts own their code and instructions. Keep Noema synthesis outside `sources/` and create supporting directories when needed.
