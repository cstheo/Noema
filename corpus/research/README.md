## Maintenance

- Zotero owns metadata, attachments, and native notes. Move synchronized Markdown through **Paper notes**; preserve UUIDs, registries, and baselines together.
- Move registered notes and selections before removing a configured field.
- Before importing, check the entire library by DOI and title. Prefer published PDFs; label author versions.
- Use existing conference/year collections: OSDI, SOSP, FAST, EuroSys, ATC, NSDI, and architecture venues.
- In surveys, link the managed PDF, publication, and Zotero item. Cite the version inspected; availability does not establish reading or mastery.
